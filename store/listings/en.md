# English store listing

## Name

Prelude

## Summary

A calm new tab for Chrome bookmarks, open tabs, and Read later. Bookmark and tab data stays local.

## Detailed description

```text
Prelude brings Chrome bookmarks, open tabs, and Read later collection into one calm new tab, so each browsing session starts with a clearer view.

Prelude reads Chrome bookmarks and the titles and URLs of open tabs to display, search, manage, and collect them. This data stays local—it is not uploaded, sold, or used for advertising. Only a web search explicitly submitted by the user is passed by Chrome to the configured default search provider.

Highlights
• Keep Chrome's existing bookmark hierarchy and add, edit, move, or delete items directly
• Use Today to focus on Pinned, Read later, and Favorites
• See tabs across browser windows and switch to any tab
• Collect the current page, a whole window, or a tab group in its original order
• Check for duplicate URLs before saving and choose whether to skip or keep a copy
• Search bookmarks, open tabs, and the web from one place
• Use Chrome's configured default search engine without changing search settings
• Fill missing bookmark titles automatically while preserving titles you enter yourself
• Choose light, dark, or system appearance
• Use Simplified Chinese, English, Japanese, Spanish, French, or Russian

Privacy and control
Prelude has no account, remote server, analytics, or advertising. Bookmarks stay in Chrome; interface preferences and temporary state stay in local browser storage. You can view, change, or delete bookmarks created through Prelude at any time in Chrome.
```
