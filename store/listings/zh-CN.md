# 简体中文商店文案

## 名称

序幕 · Prelude

## 摘要

把 Chrome 书签、当前标签页与待读收集整合进安静的新标签页；书签与标签页数据仅在本地处理。

## 详细介绍

```text
江流天地外，山色有无中

序幕把 Chrome 书签、打开的标签页和“待读”收集放进一个安静的新标签页，让每天打开浏览器的第一眼更清楚。

序幕会读取 Chrome 书签及打开标签页的标题和网址，用于展示、搜索、管理与收集；这些数据仅在本机处理，不上传、不出售，也不用于广告。只有用户主动提交的网页搜索会由 Chrome 交给当前配置的默认搜索引擎。

主要功能
• 保留 Chrome 书签原有文件夹层级，直接新增、编辑、移动和删除
• 用“今日”集中查看置顶、待读和收藏内容
• 查看当前窗口与其他窗口的标签页，并一键切换
• 把当前页面、整个窗口或标签组按原顺序收集到“待读”
• 保存前检查重复网址，可跳过或保留副本
• 同时搜索书签、打开的标签页和网页
• 使用 Chrome 默认搜索引擎，不更改搜索设置
• 自动补全新书签标题，并保留用户手动填写的标题
• 支持浅色、深色和跟随系统主题
• 支持简体中文、English、日本語、Español、Français 和 Русский

隐私与控制
序幕没有账号、远程服务器、分析工具或广告。书签保存在 Chrome 中；界面偏好和临时状态只保存在浏览器本地。你可以随时在 Chrome 中查看、修改或删除通过序幕建立的书签。
```
