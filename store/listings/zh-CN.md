# 简体中文商店文案

## 名称

序幕 · 新标签页

## 摘要

一个安静的新标签页，用来整理 Chrome 书签、当前标签页和待读内容。

## 详细介绍

```text
一个安静的新标签页，用来整理 Chrome 书签、当前标签页和待读内容。

序幕（Prelude）把 Chrome 新标签页变成日常浏览的起点。常用书签、其他窗口里的标签页、之前存下的待读内容，打开这一页就能继续整理。

序幕会读取 Chrome 书签及打开标签页的标题和网址，用于展示、搜索、管理与收集；这些数据仅在本机处理，不上传、不出售，也不用于广告。只有用户主动提交的网页搜索会由 Chrome 交给当前配置的默认搜索引擎。

常用的网页，打开就能找到
沿用 Chrome 原有的书签文件夹，直接新增、编辑、删除和拖动整理。「今日」集中呈现置顶、待读与收藏，「最近添加」帮你找回刚保存的页面。

打开的页面，接着看就好
集中查看各个窗口的标签页，切换、关闭、拖动排序，或移到其他窗口。搜索框同时查找书签与当前标签页；网址直接打开，网页搜索使用 Chrome 默认搜索引擎，不更改你的搜索设置。

没空看的，先放进待读
通过工具栏或右键菜单保存当前页面、整个窗口或标签组；默认快捷键 Alt + Shift + S 用于保存当前页面。保留标签顺序，检查重复网址，可选择跳过或保留副本。开启「保存后关闭」，只关闭本次成功保存的标签页。新书签缺少标题时会在可行时自动补全，手动填写的标题会被保留。

按你的习惯使用
支持浅色、深色和跟随系统主题，以及简体中文、English、日本語、Español、Français 和 Русский。

隐私与控制
无需注册，没有广告和分析工具。书签仍是普通 Chrome 书签，并遵循你自己的 Chrome 同步设置；界面偏好和临时状态保存在本地。即使卸载序幕，书签和文件夹也会保留，除非你自行删除。
```
