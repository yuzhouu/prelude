# Texto para Chrome Web Store en español

## Nombre

Prelude

## Resumen

Una nueva pestaña tranquila para organizar los marcadores de Chrome, las pestañas abiertas y Leer más tarde.

## Descripción detallada

```text
Una nueva pestaña tranquila para organizar los marcadores de Chrome, las pestañas abiertas y Leer más tarde.

Prelude convierte la nueva pestaña de Chrome en tu punto de partida diario. Abre un sitio habitual, encuentra una pestaña de otra ventana o vuelve a una página que guardaste para después.

Prelude lee los marcadores de Chrome y los títulos y URL de las pestañas abiertas para mostrarlos, buscarlos, gestionarlos y guardarlos. Estos datos permanecen en local: no se suben, venden ni utilizan para publicidad. Solo las búsquedas web enviadas expresamente por el usuario se entregan al buscador predeterminado de Chrome.

Tus marcadores, a mano
Conserva las carpetas que ya tienes en Chrome. Añade, edita, elimina y reordena páginas desde la nueva pestaña. Hoy reúne Fijados, Leer más tarde y Favoritos; Añadidos recientemente te ayuda a encontrar lo que acabas de guardar.

Retoma lo que estabas viendo
Consulta las pestañas de todas tus ventanas. Cambia de página, cierra lo que has terminado o arrastra pestañas para reordenarlas o moverlas a otra ventana. Busca marcadores y pestañas a la vez. Abre direcciones directamente o busca en la web con el buscador predeterminado de Chrome, sin cambiar su configuración.

Guárdalo para después
Desde la barra de herramientas o el menú contextual, guarda la página actual, una ventana completa o un grupo de pestañas en Leer más tarde. El atajo predeterminado Alt + Shift + S guarda la página actual. Se conserva el orden y puedes omitir las URL duplicadas o guardar una copia. Si activas Cerrar después de guardar, solo se cierran las pestañas guardadas correctamente. Los títulos vacíos se completan cuando es posible; los que escribes se conservan.

A tu gusto
Elige un tema claro, oscuro o del sistema. Disponible en chino simplificado, inglés, japonés, español, francés y ruso.

Privacidad y control
Sin cuentas, anuncios ni analítica. Tus marcadores siguen siendo marcadores de Chrome y respetan tu configuración de Chrome Sync. Las preferencias y los datos temporales se guardan localmente. Al desinstalar Prelude, tus marcadores y carpetas permanecen hasta que tú los elimines.
```
