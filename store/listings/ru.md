# Текст для Chrome Web Store на русском

## Название

Prelude

## Краткое описание

Новая вкладка для закладок, открытых вкладок и списка «Прочитать позже». Их данные обрабатываются локально.

## Подробное описание

```text
Prelude объединяет закладки Chrome, открытые вкладки и список «Прочитать позже» на одной спокойной и понятной новой вкладке.

Prelude читает закладки Chrome, названия и URL открытых вкладок, чтобы показывать, искать, упорядочивать и сохранять их. Эти данные обрабатываются локально: они не загружаются, не продаются и не используются для рекламы. Только веб-поиск, явно отправленный пользователем, передаётся выбранной в Chrome поисковой системе по умолчанию.

Основные возможности
• Сохранение исходной структуры папок Chrome с добавлением, изменением и удалением элементов
• Раздел «Сегодня» для закреплённых страниц, списка «Прочитать позже» и избранного
• Просмотр вкладок из разных окон и быстрое переключение между ними
• Сохранение текущей страницы, всего окна или группы вкладок в исходном порядке
• Проверка повторяющихся URL перед сохранением с выбором пропуска или создания копии
• Поиск по закладкам, открытым вкладкам и Интернету в одном месте
• Использование поисковой системы Chrome по умолчанию без изменения настроек
• Автоматическое заполнение отсутствующих названий без перезаписи введённых вручную
• Светлая, тёмная и системная темы, а также шесть языков

Конфиденциальность и контроль
В Prelude нет учётной записи, удалённого сервера, аналитики и рекламы. Закладки остаются в Chrome, а настройки и временные данные — в локальном хранилище браузера.
```
