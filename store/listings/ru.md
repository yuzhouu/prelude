# Текст для Chrome Web Store на русском

## Название

Prelude

## Краткое описание

Спокойная новая вкладка для закладок Chrome, открытых вкладок и списка чтения.

## Подробное описание

```text
Спокойная новая вкладка для закладок Chrome, открытых вкладок и списка чтения.

Prelude превращает новую вкладку Chrome в отправную точку для повседневной работы в браузере. Откройте привычный сайт, найдите вкладку в другом окне или вернитесь к странице, сохранённой на потом.

Prelude читает закладки Chrome, названия и URL открытых вкладок, чтобы показывать, искать, упорядочивать и сохранять их. Эти данные обрабатываются локально: они не загружаются, не продаются и не используются для рекламы. Только веб-поиск, явно отправленный пользователем, передаётся выбранной в Chrome поисковой системе по умолчанию.

Закладки под рукой
Сохраните привычные папки Chrome. Добавляйте, редактируйте, удаляйте и перемещайте страницы прямо на новой вкладке. Раздел «Сегодня» объединяет закреплённые страницы, список «Прочитать позже» и избранное. В разделе недавно добавленных закладок легко найти то, что вы только что сохранили.

Продолжайте с нужной страницы
Просматривайте вкладки из всех окон. Переключайтесь на страницу, закрывайте ненужные вкладки или перетаскивайте их, чтобы изменить порядок или перенести в другое окно. Ищите закладки и открытые вкладки вместе. Адреса открываются напрямую, а веб-поиск использует поисковую систему Chrome по умолчанию, не меняя её настройки.

Сохраните на потом
Панель расширения и контекстное меню позволяют сохранить текущую страницу, всё окно или группу вкладок в список «Прочитать позже». Стандартное сочетание Alt + Shift + S сохраняет текущую страницу. Порядок вкладок сохраняется; повторяющиеся URL можно пропустить или сохранить ещё раз. Если включить закрытие после сохранения, закроются только успешно сохранённые вкладки. Пустые названия закладок по возможности заполняются автоматически, а введённые вручную сохраняются.

Настройте под себя
Выберите светлую, тёмную или системную тему. Доступны упрощённый китайский, английский, японский, испанский, французский и русский языки.

Конфиденциальность и контроль
Без аккаунтов, рекламы и аналитики. Закладки остаются обычными закладками Chrome и следуют вашим настройкам Chrome Sync. Настройки и временные данные хранятся локально. После удаления Prelude закладки и папки останутся, пока вы не удалите их сами.
```
