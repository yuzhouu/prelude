# 序幕品牌与文案

## 名称

- 品牌：**序幕 · Prelude**。
- 中文对外主标题、商店名称：**序幕 · 新标签页**。
- 其他语言品牌名：**Prelude**。英文介绍标题可用 **Prelude · New Tab**。
- 产品定位：Chrome 新标签页，用于整理已有书签、当前标签页和待读内容。

界面侧栏和关于页保留「序幕 · Prelude」。品牌名称的展示调整不改变已有书签文件夹、存储键或项目仓库名称。

## Slogan

中文原句保持不变：

> 一个安静的新标签页，用来整理 Chrome 书签、当前标签页和待读内容。

英文沿用现有介绍：

> A calm new tab for organizing Chrome bookmarks, open tabs, and Read later.

宣传图可以按版面换行，但不改写、删减句子。其他语言沿用对应界面「关于」页的介绍，并与扩展简介及商店摘要保持一致。

## 图标与颜色

主图标为朱红色叠放文件夹和白色加号。文件夹左上方有小标签和短肩部，两侧竖直；浅粉后层与主色前层清楚分开。

- SVG 原稿：`public/icons/prelude.svg`；网站副本：`docs/prelude.svg`。
- Chrome PNG：16、32、48、128 px，均由同一 SVG 导出。
- 图标前层渐变：`#cd604b` → `#bf4d3f`。
- 浅色界面强调文字：`#b44d3d`；主要按钮：`#bf4d3f`；选中背景：`#faeee9`。
- 深色界面强调文字：`#e8a496`；选中背景：`#392b28`。
- 删除、错误和失败提示保留独立红色语义，使用 `--danger` 系列变量。

应用与介绍页保留白色、浅灰色背景和黑灰文字。朱红用于图标、选中状态、链接、主要按钮和少量强调；背景不铺设品牌色渐变。

## 介绍文案

从使用场景说明产品：打开常用书签，查看多个窗口的标签页，把没空阅读的内容存进待读。功能描述以当前实现为准：

- 直接使用 Chrome 书签，保留原有文件夹层级。
- 工具栏与右键菜单支持保存页面、窗口或标签组；默认快捷键只保存当前页面。
- 「保存后关闭」只自动关闭本次成功保存的标签页。
- 网页搜索由 Chrome 交给默认搜索引擎。
- 书签与标签页数据在本机处理；Chrome 书签同步取决于用户自己的设置。

完整数据说明见 `PRIVACY.md` 和 `store/privacy-practices.md`。宣传文案不代替隐私说明，也不承诺独立云同步或远程备份。
