序幕 · 新标签页

一个安静的新标签页，用来整理 Chrome 书签、当前标签页和待读内容。

获取扩展 安装说明 ↓

常用的、打开的，
都在眼前。

从找到网页，到整理好它。
日常浏览，在一页里自然接上。

书签，还是熟悉的样子

沿用 Chrome 文件夹，在新标签页里新增、编辑、拖动整理。今日与最近添加，让常用内容更好找。

多个窗口，一起看清

查找打开的标签页，切换、排序或移到其他窗口。开启并授权常用网站后，也可以在侧边栏和搜索框找到经常访问的页面。

现在没空，先放进待读

从工具栏或右键菜单收集页面、窗口与标签组。自动检查重复；开启「保存后关闭」时，只关闭成功保存的标签页。

你的浏览空间，
由你自己掌握。

无需账号，没有广告和分析工具。书签、标签页与常用网站在本机处理；只有你主动提交的网页搜索会交给 Chrome 默认搜索引擎。

了解数据如何使用 ↗

把序幕放进你的 Chrome

下载扩展安装包，解压后即可加载到 Chrome。目前通过开发者模式安装。

下载扩展 ZIP SHA-256 校验值
  1. 下载并解压 ZIP，确认文件夹内有 manifest.json。
  2. 打开 chrome://extensions，开启「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择解压后的文件夹。
  4. 打开新标签页即可使用序幕，也可以固定工具栏图标以方便收集页面。
