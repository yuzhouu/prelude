使用帮助

让序幕用起来更顺手

从书签整理到待读收集，这里是一些常见问题的说明。

获取与安装

当前提供 Chrome 扩展安装包。下载后解压到一个固定位置，再由 Chrome 加载；这不是 Chrome Web Store 的一键安装。

下载扩展 ZIP SHA-256 校验值
  1. 下载并解压 ZIP，确认解压后的文件夹内有 manifest.json。
  2. 在 Chrome 地址栏输入 chrome://extensions，打开右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择刚才解压的文件夹。
  4. 打开新标签页即可使用序幕，也可以将工具栏中的序幕图标固定以方便收集页面。

更新时，用新安装包替换原文件夹内容，再在扩展管理页点击「重新加载」。保留原文件夹路径，避免卸载导致偏好设置丢失。

日常使用

需要重新导入书签吗？

不用。序幕直接使用 Chrome 现有书签，并保留文件夹层级。你在序幕里新增、编辑、移动或删除的内容，也会体现在 Chrome 书签中。

怎样把页面留到稍后再看？

点击扩展工具栏中的序幕图标，或使用页面右键菜单，可以保存当前页面、整个窗口或标签组。默认快捷键 Alt + Shift + S 用于把当前页面加入待读；你也可以在 Chrome 的扩展快捷键设置中调整它。

保存之后，原来的标签页会关闭吗？

由「保存后关闭」选项决定。开启后只关闭本次成功保存的标签页；跳过的重复页面和保存失败的页面会保留。

搜索会使用哪个搜索引擎？

搜索框会先展示匹配的书签和当前标签页。提交网页搜索时使用 Chrome 当前配置的默认搜索引擎；序幕不会更改你的搜索设置。

如何显示或关闭常用网站？

在设置中打开「常用网站」，并在 Chrome 提示中允许访问，即可在侧边栏和搜索框查看。它默认关闭；拒绝授权不会影响书签和标签页功能。

关闭开关会停止读取和展示，但保留 Chrome 已授予的权限。隐藏的网站可在搜索框中恢复。序幕不读取完整浏览历史，也不自行统计访问次数。

书签会同步吗？卸载后还在吗？

书签仍由 Chrome 保存和管理，是否同步取决于你自己的 Chrome 同步设置。序幕不提供远程账号或备份；卸载序幕后，普通 Chrome 书签和文件夹仍会保留。

遇到问题时

先在 chrome://extensions 确认序幕已启用，并仍拥有所需权限。更新后重新打开一个新标签页，再检查问题是否存在。

提交反馈时，请附上 Chrome 版本、序幕版本、复现步骤和预期结果。截图前请遮住私人书签、网址和其他敏感信息。
