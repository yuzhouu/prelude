# 序幕 · 新标签页

[English](./README.md) · [简体中文](./README.zh-CN.md)

> 一个安静的新标签页，用来整理 Chrome 书签、当前标签页和待读内容。

序幕（Prelude）把 Chrome 新标签页变成日常浏览的起点。打开常用书签，找回其他窗口里的标签页，或继续阅读之前存下的内容，都可以从这里开始。它直接使用你已有的 Chrome 书签，原本的文件夹层级也会保留。

![序幕新标签页中的书签视图](./store/assets/screenshots/zh-CN/01-bookmarks-1280x800.png)

## 常用的网页，打开就能找到

沿用 Chrome 原有的书签文件夹，在新标签页里直接新增、编辑、删除和拖动整理。**今日**集中呈现置顶、待读与收藏，**最近添加**帮你找回刚保存的页面，不用再维护另一套收藏。

## 打开的页面，接着看就好

在一个视图里查看各个窗口的标签页，切换到想看的页面，关闭已经处理完的内容，或拖动排序、移到其他窗口。搜索时同时查找书签与当前标签页；输入网址可以直接打开，提交普通关键词则使用 Chrome 默认搜索引擎。

## 没空看的，先放进待读

通过扩展工具栏或页面右键菜单，把当前页面、整个窗口或标签组保存到**待读**；默认快捷键 `Alt + Shift + S` 可以保存当前页面。序幕会保留标签顺序，并检查重复网址。开启**保存后关闭**，就能收起本次成功保存的标签页。

新书签缺少标题时，序幕会在可行时自动补全；你亲自填写或修改过的标题会被保留。

## 安静地融入日常

浅色、深色或跟随系统，由你选择。侧栏适配较窄的窗口，界面支持简体中文、English、日本語、Español、Français 和 Русский。

无需注册，没有广告和分析工具。序幕在本机处理书签与标签页数据；书签仍保存在 Chrome 中，并遵循你自己的 Chrome 同步设置。你主动提交的网页搜索会由 Chrome 交给当前配置的默认搜索引擎。
