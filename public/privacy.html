Privacy policy

隐私政策

序幕没有远程服务、账号系统、分析工具或广告系统。书签、标签页、导航元数据和偏好数据均留在用户的浏览器中；只有用户主动提交的网页搜索会由 Chrome 交给当前配置的默认搜索引擎。

最后更新：2026-08-31

序幕只为管理 Chrome 书签、打开的标签页与“待读”内容处理必要数据。书签与标签页数据不上传、不出售，也不用于广告；只有用户主动提交的网页搜索会交给默认搜索引擎。

处理的数据

  • Chrome 书签：标题、网址、文件夹层级、标识及 Chrome 提供的同步属性。只有在用户主动添加、编辑、移动、删除或收集时才会修改。
  • 打开的标签页：标题、网址、窗口、标签组、固定、活动与音频状态，用于展示、搜索、切换和收集。
  • 导航元数据：自动补全书签标题时短暂处理顶层页面的来源网址、最终网址和标题，以关联重定向。不读取页面正文、表单、Cookie 或认证信息。
  • 本地偏好：语言、主题、侧栏状态、“保存后关闭标签页”偏好、“待读”文件夹标识及等待自动补全标题的书签标记。
  • 搜索输入：网页搜索会直接交给 Chrome 当前配置的默认搜索引擎。序幕不保存或上传查询。

用途、保存与分享

上述数据只用于用户可见的书签、标签页、搜索和收集功能。书签保存在 Chrome 的书签系统中，并可能根据用户自己的 Chrome 同步设置由 Chrome 同步。扩展偏好和自动标题标记保存在浏览器的扩展存储中。

导航关联信息只在当前浏览器会话中使用，有效期最长为五分钟，并会在关联完成、标签页关闭或信息失效后清理。除用户主动提交的网页搜索由 Chrome 交给默认搜索引擎外，序幕不向开发者、广告商、数据经纪商或其他第三方传输数据，也没有人员能够查看用户数据。

用户控制

用户可以随时在 Chrome 中查看、修改或删除书签。卸载扩展或清除扩展数据会移除序幕保存的偏好和临时标记。通过序幕建立的书签和文件夹属于普通 Chrome 书签，除非用户自行删除，否则会继续保留。

Chrome Web Store Limited Use

序幕对通过 Chrome API 获得的信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。所有数据访问都仅用于提供或改进扩展公开说明的单一用途。

Privacy policy in English

Prelude is a Chrome new-tab extension for managing bookmarks, open tabs, and Read later items. It has no remote service, account system, analytics, or advertising system. Bookmark, tab, navigation metadata, and preference data remain in the user's browser. Only a web search explicitly submitted by the user is passed by Chrome to the configured default search provider.

Data handled

  • Chrome bookmarks: titles, URLs, hierarchy, identifiers, and sync properties exposed by Chrome. Bookmarks change only after a user action.
  • Open tabs: titles, URLs, window and group identifiers, pinned, active, and audio state for display, search, activation, and collection.
  • Navigation metadata: source URL, final URL, and page title are handled temporarily while matching redirects for automatic bookmark titles. Prelude does not read page bodies, forms, cookies, or authentication data.
  • Local preferences: language, theme, sidebar state, close-after-save preference, Read later folder identifier, and pending automatic-title markers.
  • Search input: a submitted search is passed directly to Chrome's configured default search provider and is not stored or uploaded by Prelude.

Use, retention, and sharing

Data is used only for the disclosed bookmark, tab, search, and collection features. Bookmarks remain in Chrome's bookmark system and may be synced by Chrome according to the user's settings. Navigation association data is session-only, valid for no more than five minutes, and removed after resolution, tab closure, or expiration.

Except for a user-submitted web search passed by Chrome to the default provider, Prelude does not transmit data to the developer, advertisers, data brokers, or other third parties. It does not sell data, use data for personalized ads or credit decisions, build browsing profiles, or allow humans to read user data.

User control and Limited Use

Users may edit or delete bookmarks at any time. Uninstalling Prelude or clearing its data removes extension preferences and temporary markers; ordinary Chrome bookmarks remain until the user deletes them.

Prelude's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. All access is limited to providing or improving the extension's disclosed single purpose.
